# Yremote

**Modern Remote Connection & Infrastructure Management**

Yremote is a modern Windows application designed for network engineers, system administrators, and IT professionals to manage remote connections and infrastructure from one centralized workspace.

## Features

- SSH and RDP remote connections
- Hierarchical connection and folder management
- Multi-site infrastructure organization
- Device inventory with advanced search and filtering
- Device reachability monitoring
- Connection settings and management
- Dark-themed user interface

## Supported Protocols

- SSH v2
- RDP
- Telnet
- HTTP / HTTPS

## Platform

- Windows
